# 路线导航纸雕改版 · 2026-09-13

本次范围为进入路线之后的三张路线卡片及 30 / 90 / 150 / 180 天进度区。以用户提供的奶油白纸山、横向浮起卡片和弯曲纸路参考图为构图依据；首页封面不在本次修改范围。

## 视觉实现

- 三张横向纸卡：左侧字母、路线名称、简短说明；右侧为具有纸层、纤维纹理和接触阴影的书本、电脑、山峰。
- 系统学习使用蓝色 `#287dcc`，AI 协作使用橙色 `#cb812b`，专业深耕使用绿色 `#568567`。选中卡片显示对应色边框及向下的小纸角。
- 山丘、树木和远处建筑作为一张连续背景。导航文字保留为 HTML，日期与角色叠在独立 SVG 纸路上。
- 角色和日期节点使用同一组坐标，切换路线时保留各自剧情进度；日期变化时移动刘看山。
- 窄屏保持三张卡片同时显示，省略副文案，日期说明分行；为试玩退出按钮预留空间。
- 保留键盘方向键选择及清楚的焦点样式，避免切换标签后焦点被剧情抢走。减少动态效果设置下使用静态角色图和无过渡样式。
