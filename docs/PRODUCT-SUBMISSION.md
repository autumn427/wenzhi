# 问枝：先体验选择，再把一件小事带回现实

作品类型：网页版互动叙事游戏。建议赛道：跨次元游乐场 · AI 游戏与互动叙事。

正式网址：https://wenzhi.autumn427.xyz/

## 产品简介（可填写到项目介绍）

想换条路，又怕后悔。问枝让正在犹豫的学生和职场新人，把一个真实问题放进三个平行宇宙，亲自选择如何投入有限的时间，体验行动带来的模拟结果与代价。走完一条路线，就能带走一张七天行动票；想进一步比较，可以继续其他路线。现实回声从知乎公开内容中寻找相关线索，让玩家对照他人的条件和观点，再回到自己的选择。问枝不预测人生、不评判天赋，而是帮助用户把模糊的犹豫变成一个小范围、可停止的现实尝试。

## 用户与问题

目标用户是面临学习方向、作品投入、专业发展等选择的学生和职场新人。用户并不缺少建议，而是难以判断：建议基于什么条件，自己愿意承担哪种代价，下一步究竟试什么。

典型例子：一名人文学科研究生每周只能拿出两小时，想做文献整理工具，却担心学习编程影响本专业。问枝围绕用户的问题、目标、时间预算和底线展开路线，而不是把所有问题都固定成编程选择。

## 核心体验

1. **定锚**：写下犹豫的问题、180 天目标，选择时间预算和不愿牺牲的部分。
2. **分岔**：选择一个宇宙，在第 30、90、150 天作出关键选择，抵达第 180 天。正常模式由 AI 结合本宇宙已有记录续写；预设试玩使用本地剧情规则。
3. **回看**：查看结局、选择记录与模拟状态变化。走完一个宇宙即可领取本地规则整理的七天行动票，不要求先通关全部路线。
4. **现实回声**：按当前行动、阻碍和处境检索知乎公开内容，展示作者、摘录、共同话题线索和原文链接；帮助用户核对条件，不把别人的结果套到自己身上。
5. **继续比较（可选）**：探索其他宇宙，三条路线完成后开放未来辩论；已有行动票和打卡不会因开始辩论而清空。
6. **现实尝试**：行动票提供每天的小步骤、成功信号和停止规则。单路线模板全周共 90 分钟；用户可记录完成、跳过和观察结果。

## 与知乎生态的关系

知乎公开讨论承载多样的经历、观点和适用条件。问枝通过独立的知乎检索接口，为当前选择寻找可追溯的参考内容，鼓励用户进入原文继续阅读。它将“看过一条建议”转化为“对照这条建议的条件，再决定自己试什么”。

当前现实回声的关联提示是本地文本线索匹配，不是 AI 对来源事实的核验；公开内容可能是建议、讨论或个人经历，界面不自动认定为亲身经验。检索无结果或服务不可用时明确留白，用户仍能返回原路线。

模拟剧情与知乎来源分开展示。阅读来源不自动增加能力值，不改写用户已完成的选择。没有引用来源的剧情不宣称来自知乎共识。

## AI 在哪里发挥作用

正常体验包含个性化路线、行动续写、未来回信、三宇宙辩论等生成入口。最重要的生成输入是本次行动和同一宇宙的既有记录，A/B/C 只是编号。

服务端对输出进行日期、选项、时间预算、行动边界和数值引文校验。结构异常最多尝试一次修复；数值引文异常最多尝试一次仅修改评分与依据的校正，不能改写故事来支持分数。超时、服务授权问题和行动越界不会无限重试。校正后仍须通过校验，失败则不推进时间线。

这些校验减少明显的不一致，但不构成对生成内容真实性或叙事质量的保证。雷达图是模拟状态的可视化，不是心理测评、能力认证或人生预测。

## 技术实现

- 前端：React、TypeScript、Vite；纸张与纸雕视觉；路线记录、雷达图、行动票和现实回声弹窗。
- 服务端：Cloudflare Worker，提供固定业务接口，服务端调用配置的模型中转服务；知乎检索独立配置。
- 存储：浏览器 localStorage 保存处境、模拟进度、按宇宙及节点隔离的行动草稿和实验反馈；Cloudflare D1 用于已有贡献/服务数据。没有跨设备进度同步。
- 请求处理：生成中阻止重复提交；提交成功才更新状态。过期处境的响应不覆盖新处境；恢复草稿不会自动重发请求。
- 密钥：仅保存在服务端环境，未放入前端。正常模式会发送用户主动提供的问题、目标、行动和所需历史给配置的 AI 服务；现实回声发送用于检索的上下文片段。界面提示不要填写隐私信息。
- 模式：`?demo=1` 为预设试玩，不调用剧情生成模型；现实回声仍依赖联网检索。正常模式需要服务端模型可用。当前不要求知乎登录。

## 建议体验路线

快速理解：进入网站 → 先试玩 3 分钟 → 任选一个宇宙 → 完成三次选择 → 查看结局 → 带走 7 天实验 → 打开现实回声、核对原文。

验证真实 AI：退出试玩 → 输入自己的问题与目标 → 生成路线 → 提交一次具体行动 → 检查下一幕如何承接行动及代价。该流程依赖上游服务，可能需要等待；失败可以保留草稿并重试。

首次使用无需安装客户端或配置开发环境。建议评委在同一浏览器完成体验，清理浏览器数据会移除本地进度。
